## Building Now

### [Dalekta](https://dalekta.id) — WhatsApp Conversion Data Hub

Most ad platforms can see the click. The real sale often happens later in WhatsApp.

Dalekta connects **Meta Ads**, **Google Ads**, landing pages, WhatsApp conversations, lead quality, and closing revenue so businesses can answer the question that actually matters:

> Campaign mana yang benar-benar menghasilkan uang?

What Dalekta helps teams do:

- Track ad source from click to WhatsApp chat.
- See which campaign, adset, keyword, or creative produces closing.
- Send lead and purchase signals back through server-side conversion tracking.
- Read ROAS from revenue, not just clicks.
- Prioritize leads and retarget audiences from real buyer behavior.

`Ads Attribution` `WhatsApp Funnel` `Conversion API` `Lead Tracking` `Revenue Analytics`

### [Lagaligo](https://lagaligo.dev) — local-first agent engineering orchestration

Lagaligo is an open-source direction for running agent engineering as a structured mission, not a messy chat thread.

One mission becomes research, architecture, task graph, isolated workers, validation gates, and project memory. The point is simple: many agents can work, but the engineering journey still needs one accountable system.

What Lagaligo is about:

- Local-first daemon for agent engineering workflows.
- Mission planning, task graph, and worker isolation.
- Validation gates before work is accepted.
- Project memory that keeps context inspectable.
- A practical orchestration layer for developers who want agents to produce reviewable work.

`Agent Orchestration` `Local-First` `Task Graph` `Validation Gate` `Project Memory`
